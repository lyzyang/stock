# A股市场分析方法论

## 一、市场状态判定体系

### 判定维度

1. **位置维度**：当前价格与均线的相对位置
   - 价格 > MA20 > MA60：多头格局
   - 价格 < MA20 < MA60：空头格局
   - 其他：震荡格局

2. **趋势维度**：MA20的斜率方向
   - 斜率 > 0：上升趋势
   - 斜率 < 0：下降趋势

3. **量能维度**：近5日均量与近20日均量的比值
   - > 1.2：放量
   - < 0.8：缩量

4. **技术指标维度**：MACD、RSI等确认信号

### 市场状态分类

| 状态 | 条件 | 置信度 |
|---|---|---|
| 强势多头 | 多头格局 + MACD金叉 + 放量 | 0.85 |
| 弱势多头 | 多头格局 + MACD金叉 或 放量 | 0.65 |
| 多头 | 多头格局 | 0.70 |
| 强势空头 | 空头格局 + MACD死叉 + 放量 | 0.85 |
| 弱势空头 | 空头格局 + MACD死叉 或 放量 | 0.65 |
| 空头 | 空头格局 | 0.70 |
| 震荡偏强 | 震荡格局 + RSI超买 | 0.60 |
| 震荡偏弱 | 震荡格局 + RSI超卖 | 0.60 |
| 震荡 | 其他情况 | 0.50 |

## 二、市场情绪评分体系

### 评分因子

| 因子 | 权重 | 评分规则 |
|---|---|---|
| 上涨比例 | 40% | >70%: +25分, 55-70%: +10分, 30-45%: -10分, <30%: -25分 |
| 涨跌停比 | 30% | 涨停>跌停3倍: +15分, 跌停>涨停3倍: -15分 |
| 北向资金 | 30% | >5亿: +10分, <-5亿: -10分 |

### 情绪等级

| 评分范围 | 等级 | 含义 |
|---|---|---|
| 75-100 | 极端乐观 | 市场情绪过热，谨慎追高 |
| 60-74 | 偏乐观 | 市场情绪积极，可适度参与 |
| 40-59 | 中性 | 市场情绪平稳，观望或区间操作 |
| 25-39 | 偏悲观 | 市场情绪低迷，控制仓位 |
| 0-24 | 极端悲观 | 市场情绪恐慌，关注抄底机会 |

## 三、技术指标使用方法

### MA均线系统

- **MA5**：短期趋势判断
- **MA10**：短线操作参考
- **MA20**：中期趋势判断，核心均线
- **MA60**：长期趋势判断

**使用规则**：
- 价格站上MA20且MA20向上：趋势转强
- 价格跌破MA20且MA20向下：趋势转弱
- MA5金叉MA10：短期买入信号
- MA5死叉MA10：短期卖出信号

### MACD指标

**使用规则**：
- DIF金叉DEA：买入信号（金叉）
- DIF死叉DEA：卖出信号（死叉）
- MACD柱状图由负转正：趋势转强
- MACD柱状图由正转负：趋势转弱

### RSI指标

**使用规则**：
- RSI > 70：超买区域，关注回调风险
- RSI < 30：超卖区域，关注反弹机会
- RSI从超卖区回升至50以上：趋势转强
- RSI从超买区回落至50以下：趋势转弱

### KDJ指标

**使用规则**：
- K金叉D：买入信号
- K死叉D：卖出信号
- J值 > 100：超买，可能回调
- J值 < 0：超卖，可能反弹

### 布林带指标

**使用规则**：
- 价格接近上轨：超买，关注压力
- 价格接近下轨：超卖，关注支撑
- 布林带收口：即将变盘
- 布林带开口：趋势加速

## 四、策略建议体系

### 多头市场策略

| 状态 | 策略 |
|---|---|
| 强势多头 | 趋势跟踪：回踩MA10/MA20可建仓，加仓 |
| 弱势多头 | 偏多操作：逢低买入，控制仓位 |
| 多头 | 趋势跟踪：顺势而为 |

### 空头市场策略

| 状态 | 策略 |
|---|---|
| 强势空头 | 空仓等待：不做多，可轻仓试空 |
| 弱势空头 | 偏空操作：逢高减仓，降低仓位 |
| 空头 | 防御为主：减少仓位，等待转机 |

### 震荡市场策略

| 状态 | 策略 |
|---|---|
| 震荡偏强 | 高抛低吸，上方压力位减仓 |
| 震荡偏弱 | 低吸高抛，下方支撑位加仓 |
| 震荡 | 区间操作，严格止损 |

## 五、风险提示

1. **数据延迟风险**：实时行情数据可能存在延迟，非交易时段数据不更新
2. **指标失效风险**：技术指标在极端行情下可能失效
3. **情绪误判风险**：情绪指标基于历史数据，可能无法预测突发事件
4. **投资建议风险**：本工具提供的分析仅供参考，不构成投资建议
5. **市场风险**：股市有风险，投资需谨慎

## 六、使用建议

1. 结合多种指标综合判断，避免单一指标决策
2. 关注市场状态变化，及时调整策略
3. 设置止损止盈，控制风险
4. 定期复盘，验证策略有效性
5. 保持理性，不被情绪左右
